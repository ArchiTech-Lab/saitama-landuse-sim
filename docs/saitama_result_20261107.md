# 埼玉県 土地利用シミュレーション 結果（2026-11-07）

前提：コンパクトシティ極限（各Xで生き残った駅のコア円r=1200mに全員が住む）。500m格子・EPSG:6677。県内の格子は3,797.5km²（N03 3,797.2km²と差0.01%）。
被覆率＝「到達圏の被覆率（居住を除く）」。分母は県内かつ非水域かつ非居住（コア円外）のセル。分子は農地側＝駅から車でY分以内、工業側＝ICから一般道でZ分以内。競合は両方に数える。95%超で飽和。
速度は現実的（道路なし面12km/h）。高速道路は使わない（駅からもICからも一般道のみ）。

## 問い3：競合の面積と場所（X=40・Y60・Z15・現実的）

競合は1928km²で、非居住地の61.4%を占める。象限別の割合は北東31.0%／北西28.4%／南東36.2%／南西4.5%。県の東半分では非居住地の90.6%が競合、西半分（秩父・山地側）は37.0%。競合セルの駅までの中央値は6分、ICまで8分で、競合でない非居住地は駅まで中央値23分。つまり競合は平野部で駅もICも近い土地に集中し、農地と工業が奪い合う。山地側は駅から遠く、農地のみか緑地になる。

## 妥当性

- 道路経路長÷直線距離の中央値＝1.258（駅から30分以内・直線2km以上、p10 1.12／p90 1.51、n=8,307）。目安は1.05〜1.6で範囲内。
- 全国の生存駅数は公開済みリプレイとXごとに一致。撤退地域（未達クラスタ）はv2では全Xで0。

## 限界

- 農地・工業は到達圏のみを塗る。標高・傾斜・現況の森林/市街は考慮しない（秩父山地も到達圏なら農地に塗られる）。
- 道路は主要道（高速・国道・主要地方道・県道・市道の一部＝OSM の motorway/trunk/primary/secondary/tertiary）のみ。それ以外は一律12km/hの面として扱う
- 所要時間は渋滞・信号・時間帯を反映しない。速度は仮定値で実測ではない
- 駅からの時間Yも ICからの時間Zも一般道のみ（高速道路は使わない）の保守的な値。ICは Z の始点としてのみ使う
- 食料自給率・収量・経済価値は算出していない（土地の配分のみ）
- 水域（区分外）は L03-b 2016年版。セル中心がN03県境内のものを県内とする（500m格子の判定誤差あり）
- 生存駅は本州全体の統合モデル（v2）の結果を県境の外側30kmまで含めて使う。撤退地域は v2 では全Xで0（未達クラスタなし）
